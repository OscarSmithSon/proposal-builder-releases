# Proposal Builder: downloads

Installers for the 3 Monkeys AV Proposal Builder. This repository holds release files only: no source code,
no keys. The installed app checks here for updates each time it starts.

Download the latest version from the [Releases page](../../releases/latest):

- **Windows:** `Proposal-Builder-Setup-x.y.z.exe`
- **Mac:** `Proposal-Builder-x.y.z-mac.dmg`

On first launch, open File > Settings, paste your AroFlo API token and choose the spec sheets folder.
